# Кандидат 0.1.0-rc.1

Реализованы локальный журнал, чек-листы, фотографии, архив, резервные копии, отчёты, API обмена и разрешение конфликтов. Добавлены доменные тесты и Apple CI.

Подтверждено на Windows: интеграционный сценарий sync API. Не подтверждено: компиляция Swift, запуск iOS-приложения, камера и VoiceOver. Кандидат остаётся на проверке до выполнения Apple-checks на Mac. Публикация и установка на устройство не выполнялись.
